Classroom Electricity Waste Tracker

A beginner-friendly Python project to track electricity wastage in college classrooms.

Problem Statement

Electricity is often wasted when fans and lights are left switched on unnecessarily in empty classrooms. This project helps record and monitor such cases.

Objectives

- To identify electricity wastage in classrooms.
- To record reports about fans and lights.
- To maintain a list of reported appliances.
- To display a summary of electricity wastage reports.

Features

1. Submit electricity wastage reports.
2. View submitted reports.
3. Display a summary of fan, light and other reports.

Python Concepts Used

- Variables and data types
- Input and output
- Operators
- If-else statements
- Loops
- Lists
- Strings
- Functions
